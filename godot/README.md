# Only Up Alpha Mobile — protótipo Android
Protótipo jogável em Godot 4.3, separado da reconstrução Unity. Inclui percurso vertical procedural, personagem 3D, pulo, controles de toque e câmera por arrasto. Não contém o mapa/modelos originais do jogo Windows.

O workflow `Build Only Up Alpha Android prototype` exporta APK ARMv7 e publica como artefato do GitHub Actions.
